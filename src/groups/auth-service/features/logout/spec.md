# 契约规格：logout（v1.0）

## 1. 一句话目标
销毁一个会话：删除 token 对应的会话记录。幂等、永远成功。

## 2. 输入
- `token`：非空字符串

## 3. 输出
成功 → `void`（无错误码——登出不该让用户看到失败）

## 4. 错误码
- `INVALID_INPUT` (400)：token 为空（组合根 zod 兜底）

## 5. 端口
- `sessions: SessionStore` —— 删除会话
- `logger: Logger` —— 记录登出事件

## 6. 不变量 / 边界情况
- 幂等：token 不存在也返回成功
- token 全文不得入日志
- 【不】负责：清理用户其他会话、统计在线人数
