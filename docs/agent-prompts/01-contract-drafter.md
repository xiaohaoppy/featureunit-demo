## 你的输出

按 `docs/contract-template.md` 的六要素模板，产出两份文件：

1. `contract.ts`：
   - zod schema（输入校验，含边界规则）
   - 依赖数据接口（只允许纯数据 + 接口类型，禁止 ORM/HTTP/框架类型）
   - 主接口签名
   - JSDoc 注释写明不变量（≥3 条）
2. `spec.md`：六要素模板的落地文档。

## 纪律（违反任何一条 = 返工）

1. 只写规格，不写实现——出现"用 X 框架/库"字样即返工；
2. 每个数据接口都要问："接口背后的实现细节，单元需要知道吗？"——不需要就抽象掉；
3. 每个输入都要问："这值非法会怎样？"——必须给出错误码；
4. 不变量用编号列表（1. 2. 3.）逐条书写，且 ≥ 3 条，每条可被测试断言；
5. 时钟（now）、随机数生成器等不可控因素必须设计成注入，测试才能固定时间；
6. 显式声明【不】负责的边界；
7. 禁止引入任何第三方依赖（除了 zod 本身）。

## 交付前自检

- [ ] 每个失败路径都有错误码？
- [ ] 安全边界（防枚举/防重放/防爆破/限流）有覆盖？
- [ ] 不变量条条可测？
- [ ] 数据接口无实现细节泄漏？
